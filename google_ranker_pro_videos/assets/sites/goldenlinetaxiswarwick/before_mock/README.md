# Golden Line "before" website: an illustration

`index.html` is a deliberately dated website made for the Golden Line testimonial video, because the client asked for "some basic website design" to stand in for the old site. It is **not** a capture of Golden Line's real previous website.

- It has no phone numbers, prices or claims.
- `before_desktop.png` (1440 x 900) and `before_mobile.png` (390 x 844 at 2x, not mobile-friendly on purpose) are Chromium screenshots of it.
- The video labels it "BEFORE · illustration", and the end card says so too.
