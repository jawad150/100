## Before you publish: claims that need evidence

The voices and faces are AI re-creations from the scripts. Under UK advertising rules (the CAP Code, and the DMCC Act 2024 on fake reviews), these spoken lines are claims that must be true and provable. Each client also needs to give written OK for the re-creation.

| Video | Lines to verify |
|---|---|
| Organic Fostering | "rebuilt our site, fixed the technical issues, got our local profile working for Manchester" (confirm this was Google Ranker Pro's work); "page one for the searches that matter"; "real enquiries every week". |
| Leam Taxis | "this is our Search Console … see these clicks": the screen shows **Business Profile calls**, since we have no Search Console export for Leam. "Flatline, all of last year": no 2025 data was supplied. "Number one for taxis in Leamington Spa" needs a dated ranking screenshot. "The phone's ringing all day". **Mispronounced town:** the generated voice says "Leamington *Spey*", rhyming with "day". The caption says "Spa". Regenerate that line before publishing. |

I left both out because they would show a ranking we can't prove. Send a dated ranking screenshot and I'll add it. |

## Rebuild

```bash
cd pipeline/fostering
# clips -> workspace3/frames/{of2,leam2,york,golden,coventry,zentro} (ffmpeg -q:v 2, from 00000.jpg), manifest.json
python3 grp_prep.py mattes of2 leam2 york golden coventry zentro    # person mattes (RVM, CPU)
python3 grp_prep2.py golden                                          # Golden Line laptop quads (shot 1)
python3 grp_prep2.py leam2 && python3 grp_prep2.py leam2fit && python3 grp_prep2.py leam2swing   # Leam monitor + finger
python3 grp2_audio.py all                                            # dialogue + SFX + original music beds
for n in of leam york golden coventry zentro; do
  FOSTER_FPS=24 python3 render.py grp2_$n --audio ../../workspace3/audio/grp2/${n}_mix.wav
done
```

**Shared code:**
- `grp_base.py`: footage, remap cuts, transitions, green-screen keying.
- `grp_brand.py`: logo, end card, captions, cards.
- `grp_kit.py`: text, panels, browser cards, captions engine.

The word timings live in `edits/asr/*.json` (faster-whisper medium.en).
